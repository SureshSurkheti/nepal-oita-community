Set a member's number

Local tool. Nothing is uploaded and nothing leaves this machine.

Never type a phone number into data/members.json itself. That file is downloaded by every visitor to the site. Paste only the hash this tool prints. The hash cannot be read back into a number.

Spaces, dashes, a leading 0 and a +81 country code are all fine — they are stripped before hashing, so the member can type it however they like.

Then

  1. Open data/members.json.
  2. Find that member and set their "hash" to the value above.
  3. Repeat for each member, and publish the site.

Keep the number itself in whatever the committee already uses as its register — a spreadsheet, the paper forms. This tool does not store it.
